# 关于宝宝资料卡

这是一个纯前端静态网页，不需要安装依赖。

## 功能

- 手机优先的填写页面
- 自动保存到浏览器本地
- 复制基础页面链接
- 调用系统分享基础页面
- 导出成图片
- 可爱粉色系卡片风格
- 隐私模式，不分享已填写内容

## 直接打开

双击打开 `index.html` 就能使用。

## 本地预览

如果你想让同一局域网里的手机访问，可以在这个目录打开命令行后运行：

```bash
py -m http.server 8123
```

然后把电脑当前局域网 IP 的这个地址发到手机里，例如：

```text
http://192.168.1.8:8123/
```

## 分享给微信好友

如果只是本机打开，复制出来的是本地链接，别人不一定能直接访问。

想让微信好友也能随时填写，建议把整个 `cute-baby-card` 文件夹上传到静态托管平台，例如：

- GitHub Pages
- Netlify
- Vercel
- 你的 NAS 或家里路由器网页空间

上传后，把网页地址发给好友即可。

## GitHub Pages 发布

如果你要用 GitHub Pages，可以按下面做：

1. 在 GitHub 新建一个公开仓库，例如 `cute-baby-card`
2. 把这个文件夹里的文件上传到仓库根目录
3. 进入仓库的 `Settings`
4. 打开 `Pages`
5. 在 `Build and deployment` 里选择：
   - `Source`: `Deploy from a branch`
   - `Branch`: `main`
   - `Folder`: `/ (root)`
6. 保存后等待几十秒到几分钟
7. GitHub 会给你一个公开地址，例如：

```text
https://你的用户名.github.io/cute-baby-card/
```

这个地址就是能发给微信好友填写的基础页面。

## 隐私说明

- 网页里的填写内容默认只保存在当前设备浏览器本地
- 分享链接时只分享基础页面，不会附带你填写过的资料
- 如果你想把自己填写好的内容发给别人，建议使用“保存成图片”
- 不再使用 `?data=...` 这种带内容的分享链接
